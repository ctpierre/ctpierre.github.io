
COMPILATION SITE INTERNET

Pour la construction de l’architecture du site internet, Jekyll se base sur le fichier index.html

Celui-ci utilise le layout default (dossier _layouts)

Le layout default.html définit la page d’accueil du site 
	le head.html : contient tout ce qui doit être chargé comme bibliothèque
	le header.html : c’est le contenu de la première page du site avec 
		la nav bar
		le titre du site…
		la deuxième page du site : activites.html accessible en scroll
